USP Fashion Halloween is a web app where three iconic USP campus characters, the EACH coati (quati), the café hen (galinha), and FLUSP, the mascot of the university’s free software group, try on costumes from different fashion eras and horror themes.
Users pick a character and a style: eight fashion eras (from 70s Disco to Cyber-Organic 2026) or eight horror specials (Vampire, Witch, Mummy, Zombie, Ghost, Frankenstein, Creepy Clown, Werewolf). The character’s photo is instantly restyled with an era-specific color filter and a hand-drawn SVG outfit that can be dragged and resized. Horror styles add a flickering frame, a dark vignette, and dripping blood.
An open-weight language model (dots-3-note-preview, served through OpenRouter’s free tier) then acts as a stylist. Given each character’s personality traits and the chosen style, it generates a short costume description, explains why the look works, suggests extra accessories, and has the character react in first person, loving or complaining about the outfit.
To estimate how well a style suits a character, the app combines the model’s own fit score with a local tag-based affinity calculation. It shows both a match percentage and an AI-versus-rules agreement score, presented honestly as a style-affinity estimate and not as a guarantee of accuracy.
Since free models can hit rate limits, all 48 looks (3 characters × 16 styles) are pre-generated and cached in a JSON file. The live demo therefore runs instantly and keeps working without internet access, while a simple local fallback covers any combination that is missing.
